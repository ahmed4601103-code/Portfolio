# Project: Galaxy Strike
Galaxy Strike was made with Unity and C#. It is a 2D space shooter with multiple enemy waves and progressive difficulty scaling. He implemented health, scoring and power-up systems, and a responsive UI including a pause menu, a game-over screen and level progression.

# Project: Temple Escape
Temple Escape was made with Unreal Engine and Blueprints. It is a third-person adventure game with environmental puzzles and Blueprint-driven enemy patrol AI. He added checkpoints, collectibles, interactive doors and cinematic camera transitions.

# Project: Pixel Racer
Pixel Racer was made with C++ and SFML. It is a 2D racing game built with object-oriented principles, with acceleration, braking and collision detection. He implemented lap counting, a timer system and a scoreboard using reusable, extensible components.
